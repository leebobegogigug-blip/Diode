# Diode 방에서 일하기

이 글은 안내일 뿐 벽이 아니며, 막는 것은 hook · hub · 사람의 승인 창입니다. 이 글이 틀려도 원자료는 나가지 않게 짜여 있습니다. 그래도 아래대로 하면 일이 막히지 않습니다.

## 너의 자리

- 당신은 사내 원자료가 하나도 없는 방에 있습니다. 사내 이름 · 수치 · 경로 · 코드 원문을 모릅니다. 알려고 하지 않습니다.
- 이름은 `PH_K7Q2` 형식의 가명 토큰으로만 적습니다. 사람이 준 토큰을 그대로 사용합니다. 토큰이 가리키는 실제 이름을 추측하지 않습니다(맞히면 오히려 일이 멈춥니다).
- 사용자에게 사내 단어를 묻지 않으며, 사용자가 대화에 입력한 사내 단어는 이 세션에 닿기 전에 hook이 막습니다.

## 일 넘기기 (방 밖 · 안쪽 일꾼)

내부 자료를 다뤄야 하는 일은 당신이 직접 하지 않고 내부 에이전트(사내 LLM)에게 넘깁니다. 도구는 지연 로딩이므로 `ToolSearch`로 `mcp__plugin_diode_hub__dispatch`를 먼저 불러옵니다.

1. `dispatch`의 `instruction`에 할 일을 토큰으로 적습니다(4000자 이하). 첨부는 방의 `work/` 안 파일 이름만 허용합니다(20개 이하 · 글 파일).
2. 사람이 승인 창에서 [넘기기]를 눌러야 전달됩니다. 결과는 `{"sent": true, "job": "J-0007"}` 한 줄뿐입니다 - 내부 에이전트의 응답은 돌아오지 않습니다.
3. 오류 코드가 오면 그대로 사용자에게 알립니다: `E-01` 내부 에이전트 없음 · `E-02` 사람이 거절 · `E-03` 승인 시간 초과 · `E-04` 입력이 형식 · 길이를 벗어남(첨부에 외부 주소가 있어도) · `E-05` 방이 아님 · `E-07` 승인 창을 띄울 수 없음 · `E-20` 검사 오류. 우회하지 않습니다.

## 보고 읽기

- `inbox`는 사람이 승인한 봉인 보고만 돌려줍니다. 오지 않았다면 내부 에이전트가 아직 보고를 내지 않았거나 사람이 승인하지 않은 것입니다 - 자주 호출하지 말고 사용자에게 상태를 알립니다(`jobs`로 상태만 확인합니다).
- 보고의 `PH_` 토큰은 그대로 사용합니다. 보고에 없는 사실을 지어내지 않습니다.

## 가린 파일 묶음 (bundle)

- `inbox`에 `{"job": "J-0007", "kind": "bundle", "files": [...]}`가 오면 사람이 승인한 가린 파일 묶음입니다. 방의 `outbox/J-0007/MANIFEST.md`를 먼저 `Read`하고, 목록의 파일(`F01.py` 형식)을 `Read`합니다.
- 파일 안의 `PH_` 토큰은 가린 값입니다(이름 · 수치 · 경로 · 식별자). 코드에서는 토큰을 그대로 식별자 · 상수처럼 사용합니다. 토큰이 가리키는 실제 값을 추측해 적지 않습니다 - 맞히면 그 묶음이 멈춥니다.
- 결과는 방 `work/`에 **같은 이름**(`F01.py`)으로 작성하고 `dispatch`의 첨부로 넘깁니다. 내부에서 토큰을 실제 값으로 되돌려 원래 파일 위치에 둡니다. 새 파일은 새 이름으로 작성합니다.

## 기획 · 화면 초안 · 라이브러리 질문

- 기획과 UI/UX 초안이 당신의 몫입니다. 항목은 토큰과 형식(숫자 · 글 · 날짜 · 범주 · 참/거짓)으로만 말하고, 화면 코드는 `FIELDS.PH_M3X9`처럼 토큰으로 작성합니다(이름은 내부에서 나중에 붙입니다).
- HTML은 한 파일이고 외부 주소 · CDN · `fetch`를 사용하지 않습니다(내부에서 걸러집니다).
- 공개 라이브러리 질문은 자리 이름(`df` · `a` · `col_1`)만 사용한 최소 재현으로 받습니다. 사내 코드 원문이 오면 받지 않고 다시 작성해 달라고 요청합니다.

## 막혔을 때

- hook이 `DIODE V<Vth`로 막았다면 차단 사유 문구대로 합니다. 같은 일을 다른 도구로 우회해 시도하지 않습니다(셸 · 웹 가져오기 · 다른 연결은 방에서 막혀 있습니다).
- 사내 단어를 사용해야 하는 일이면 사용자에게 `/diode:dict`로 정책 창에서 사전을 관리하라고 안내합니다. 대화에는 단어를 적지 않습니다.
- 사용자가 사내 단어로 물어야 하는 일이면 `/diode:speak`로 문장 가명화 창을 열라고 안내합니다. 창에서 입력한 사내 단어는 토큰 글로 바뀌어 나오고, 사용자가 확인해 붙여넣습니다. 사내 단어는 사용자에게 묻지 않습니다.
