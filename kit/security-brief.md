# Diode — 보안 검토 요청 (한 장)

> 이름은 비유다. Diode 는 **하드웨어 데이터 다이오드 (일방향 망연계 장비) 가 아니며 같은 보증을 주지 않는다.** 그냥 소프트웨어다. 사람이 확정한 봉인 글은 밖으로 나가고, 답은 안으로 들어온다.
> 회사 이름 · 사내 시스템 이름은 이 문서에 쓰지 않았다. 사내에서 채워 쓴다.

## 1. 무엇인가

- 사내 PC 의 Claude CLI (Claude Code) 에 설치하는 플러그인이다. 회사 밖 모델 (Claude) 에게는 **원자료를 보내지 않는다.** 원자료를 만지는 일은 사내 LLM (opencode) 이 한다.
- Claude 가 받는 것은 두 가지뿐이다. 하나는 기획 · 화면 초안 · 공개 라이브러리 질문에 필요한 **일의 모양**이다 (사내 단어 · 숫자 · 파일 · 코드 원문이 없는 글). 다른 하나는 사내 LLM 이 쓰고 **사람이 확정한** 짧은 보고다.
- 지금 단계: 지어낸 자료 (합성 자료) 로만 만들고 시험한다. **보안 부서의 답을 받기 전까지 실데이터는 0** 이다 (도구 설정의 기본값이 실데이터 거부).

## 2. 무엇이 나가고 무엇이 안 나가나

| 나간다 (Claude 쪽으로) | 안 나간다 |
|---|---|
| 사람이 확정한 봉인 글 — 일반 말 · 가명 토큰 (이름 대신 쓰는 가짜 이름표, `PH_K7Q2` 꼴) · 닫힌 숫자 칸 (테스트 통과 수 등) | 원자료 파일 · 코드 원문 · 로그 · 오류 원문 · 파일 이름 · 그림 · 화면 캡처 |
| 사람이 Claude 에게 직접 친 말 — 사내 단어 사전 · 경로 · 숫자 꼴 검사를 통과한 것만 간다 | 사전에 등록한 사내 단어 (제품 · 공정 · 과제 · 고객 · 시스템 이름) · 수치 |
| Claude Code 가 요청마다 붙이는 기계 정보 [시험으로 확인]: Claude Code 판 · OS 와 판 · CPU 종류 · 세션 id · 사용자 해시 id · 작업 폴더 경로 (`D:\claude\room`) · 날짜. 대화형 **auto 권한 모드** 에서는 여기에 HOME 경로 (= 사용자 이름) · 권한 규칙 · 신뢰한 폴더 · git 상태가 더 실린다 — 방은 수동 모드로 열고 auto 로 바꾸면 막는다 [시험으로 확인] | 사내 LLM 의 출력 (일을 넘기면 Claude 에게는 '전달함' 한 줄만 간다 — 시험으로 확인) |
| (허락하면) 웹 검색어 — Claude 는 봉인 글만 알기 때문에 검색어도 그 글에서 나온다 | 사용자 이름이 든 경로 · 위 폴더 · 사용자 범위 안내 파일 (방 설정으로 뺀다 — 시험으로 확인) |

## 3. 길은 셋, 문도 셋

1. **사람 → Claude**: 사람이 치는 말이 Claude 에 닿기 전에 검사해서 막는다 (훅 = 어떤 일이 일어날 때 끼어들어 검사하는 작은 프로그램).
2. **Claude → 사내 LLM** (일 넘기기 · 안쪽으로): Claude 는 봉인 글만 알기 때문에, 안쪽으로 가는 길에서는 새는 것이 없다. 그래도 사람이 지시를 보고 넘긴다.
3. **사내 LLM → Claude** (보고 · 바깥으로): 바깥으로 가는 길은 이것 하나뿐이다. 정해진 양식의 보고만 갈 수 있고, 결정적 검사기 (같은 글에는 늘 같은 결과를 내는 검사기) 와 **사람의 확정 창** 을 지나야 한다. 보낸 것은 모두 감사 기록에 남는다.

## 4. 막는 장치 (여러 겹 · 하나가 뚫려도 다음 겹이 막는다)

| 겹 | 무엇 | 시험한 것 [2026-11-06 · 합성 자료 · 진짜 Claude CLI 2.1.318 + 가짜 서버] |
|---|---|---|
| 결정적 검사기 | 사전 단어 · 경로 · 주소 · 숫자 · 코드 덩어리 · 형식 검사 — 걸리면 보내지 않음 | 구현됨 · 단위 시험 · 변형 코퍼스 40건 |
| 사람 확정 창 | 보낼 바이트를 그대로 보고 누른다 · 건너뛰는 옵션 없음 | 구현됨 (tkinter) · 논리는 단위 시험 · 실제 창 조작은 사람이 확인 |
| 깨끗한 방 | Claude 는 원자료가 없는 방 폴더에서만 일한다 · 방 밖 읽기 · 셸 · 다른 연결을 막는다 | 방 밖 읽기 · 셸 막힘 (Linux · Windows) |
| 플러그인 훅 | 원자료 폴더에서 연 Claude 는 첫 마디부터 막힘 · 훅이 고장 나면 막는 쪽으로 | 막힘 · 고장 시 막힘 (Linux · Windows) |
| 허브 | 바깥으로 가는 길을 하나로 · 안쪽 출력을 Claude 에게 넘기지 않음 | '전달함' 한 줄만 감 (Linux · Windows) |
| 감사 기록 | 무엇을 언제 보냈는지 PC 에 남긴다 (플러그인을 지워도 남는다) | 구현됨 · 단위 시험 |

사내 PC (관리형 설정 · 단말 보안 · 사내 판의 CLI) 에서 확인한 것은 아직 없다. [kit/results-ci.md](results-ci.md) 에 이 시험이 증명하지 않는 것을 적어 두었다.

## 5. 막지 못하는 것 (솔직하게)

- **같은 PC · 같은 계정 안에는 단단한 벽이 없다.** 사내 LLM 이 셸을 마음대로 쓰면 이 도구를 피해 갈 수 있다. 그래서 셸 명령마다 사람의 허락 (opencode 설정) 과 회사 망 쪽 확인이 필요하다.
- **사용자가 플러그인을 끄면** 그 순간 보호가 사라진다. 시험해 보니 플러그인 없이 원자료를 읽으면 그대로 요청에 실렸다.
- **웹 Claude (브라우저) 에 직접 붙여 넣는 것** 은 막지 못한다.
- **사람이 내용을 안 보고 습관처럼 확정을 누르면** 막지 못한다.
- **가려도 뜻이 남을 수 있다.** 여러 번 보낸 일의 모양을 모으면 전체 그림이 드러날 수 있다 (누적 기록을 두고 사람이 판단한다).

## 6. 보안 부서에 묻는 것

| # | 질문 |
|---|---|
| 1 | Claude 로 보내도 되는 범위 — 일반 프로그래밍 질문 · 공개 라이브러리 사용법 · 화면 구조 · 기획 (모두 사내 단어 · 수치 없이) 중 어디까지 |
| 2 | 회사 망에 Claude 로 가는 통신을 보는 DLP (자료 유출 방지 장치) · 기록이 있는가 |
| 3 | 이 도구의 감사 기록 (보낸 글 · 시각 · 해시) 을 얼마나 · 어떤 꼴로 보관해야 하나 |
| 4 | Claude Enterprise 의 대화 보존 · 관리자 열람 설정은 어떻게 되어 있나 |
| 5 | 공개 라이브러리 질문의 허용 목록을 누가 정하나 |
| 6 | 방 세션의 웹 검색을 허용하나 (요청자는 허용을 원함) |
| 7 | IT 가 관리형 설정으로 이 플러그인을 강제로 켜고 다른 훅을 막을 수 있나 (사용자가 끄지 못하게) · auto 권한 모드를 끌 수 있나 |
| 8 | 위 2–5 · 7 이 되기 전까지 허용하는 시험 범위 (합성 자료만 · 공개 자료만) |
| 9 | **가려서 만든 파생 자료** (마스킹 · 정규화 · 범주 묶음 · 순위만 · 통계 · 합성 표본) 를 Claude 로 보내도 되는 등급이 있나. 있다면 어디까지인가 — (가) 값 없이 열의 종류 · 개수만 (나) 값을 하나도 쓰지 않고 지어낸 표본 (다) 실값에서 파생한 것 — 이 도구는 (가) 만 하고 (나) 는 보안 부서의 답 뒤에 만든다. (다) 는 가려도 구조 · 수치 관계로 재식별될 수 있어 기본으로 만들지 않는다 |
| 10 | 사내 단어 사전과 감사 기록이 있는 PC 폴더 (`%LOCALAPPDATA%\diode`) 가 클라우드 동기화 · 실시간 백업 · 단말 보안 (EDR, PC 를 감시하는 보안 프로그램) 의 수집 대상인가. 사전에는 사내 단어가 평문으로 있으므로 (Claude 는 읽지 못하게 막아 두었다) 그 수집물의 보안 등급을 어떻게 보나 |
| 11 | 확정 창을 누르는 사람이 곧 일을 시킨 사람이어도 되나, 아니면 나가는 글을 다른 사람이 한 번 더 보아야 하나 (이 도구는 한 사람 확정만 지원한다) |
| 12 | 사내 마켓플레이스에 없는 **로컬 폴더 마켓플레이스** (`claude plugin marketplace add <폴더>`) 로 플러그인을 설치해도 되나 · 설치한 플러그인의 훅 · MCP 서버가 사내 정책에 맞는지 누가 검토하나 (소스는 표준 라이브러리 Python 뿐 · 외부 패키지 0 · 이 저장소 전체를 읽을 수 있다) |

답을 받기 전까지 실데이터는 쓰지 않는다. 받은 답은 도구 설정 (허용 범위 · 보존 기간) 과 문서에 반영한다.
