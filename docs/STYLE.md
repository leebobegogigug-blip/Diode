- hook · hub · plugin · session · prompt · skill · marketplace 같은 기술 명사는 영어로 씁니다. 처음 나올 때 괄호로 짧게 풉니다: `hook(도구 실행 직전에 검사하는 장치)`.
- README는 원래 기준대로 기술 명사를 영어로 쓰고 일상 명사는 한국어로 씁니다(junction · forward bias · depletion layer · sealed report · pseudonym token 등).
