# Diode 매뉴얼

> **개발 중 (v0.0) — 훅만 있습니다. 허브 · 확정 창이 없어 아직 쓸 수 없습니다. 설치하지 마세요.** 이 문서는 뼈대입니다. 비어 있는 절은 v0.1 부터 채웁니다.

**이름은 비유입니다 — 하드웨어 데이터 다이오드가 아닙니다.** 일방향 망연계 장비와 같은 보증을 주지 않습니다.

Claude Code 에 설치하는 플러그인 하나입니다. 스킬 · 훅 · MCP 허브 · 명령 · 표준 라이브러리 프로그램이 한 묶음으로 들어갑니다 ([기획서 › 00](PLAN.md#00-한-장-요약)). 지금 있는 것은 그중 뼈대와 자리표시 스킬 · 자가 점검뿐입니다.
소개는 [README](../README.md), 설치 절차는 [INSTALL.md](../INSTALL.md), 사내 마무리의 경계는 [INHOUSE.md](INHOUSE.md) 에 있습니다.

## 이 도구가 못 하는 것

도구가 있다는 사실이 "안전하다" 는 착각을 만들지 않게, 먼저 적습니다 ([기획서 › 02](PLAN.md#02-먼저-정할-것--이-도구가-할-수-없는-일)).

1. **허용 범위는 회사가 정합니다.** 어떤 등급의 무엇이 Claude 로 가도 되는지는 보안 부서가 정합니다. 이 도구는 그 범위를 기계로 지키는 장치일 뿐이고, 정해 주지 않으면 기본값은 **아무것도 안 보냄** 입니다. 법적 판단 · 회사 승인 · 회사 망 DLP 를 대신하지 못합니다.
2. **같은 PC 안에는 단단한 벽이 없습니다.** 사내 LLM 이 셸을 쓰면 그 계정이 할 수 있는 일은 다 합니다 (`claude` 를 직접 부르기 · 설정 파일 고치기). 여러 겹으로 막지만 벽은 아닙니다.
3. **사람이 마지막 문입니다.** 확정 창이 있어도 읽지 않고 누르면 소용없습니다.
4. **너무 많이 막으면 사람은 도구를 끕니다.** 쓰기 쉬움도 보안 성질입니다.
5. 보안 부서가 허용 범위를 정하기 전까지 **실데이터는 쓰지 않습니다** (AL-10).

## 설정

## 명령

`python diode.py <명령>` 으로 부릅니다. 종료 코드는 `0` OK · `1` 점검 실패 · `2` 사용법 오류 · `3` 사람 확인 필요이고, 점검 출력의 마지막 줄은 `결과: OK` · `결과: 확인 필요` · `결과: 점검 실패` 중 하나입니다 ([규칙 › S-03](../RULES.md#규약)).

| 명령 | 하는 일 | 지금 (v0.0) |
|---|---|---|
| `version` | `Diode 0.0.1` 을 찍습니다 (`--version` 도 됩니다) | 있음 |
| `help` | 도움말 (`-h` · `--help` 도 됩니다) | 있음 |
| `check` | 자가 점검 — 파이썬 판 (3.8 이상) 과 데이터 폴더 자리를 보입니다. 아무것도 만들거나 바꾸지 않습니다 | 있음 |
| `mcp` | 허브 (MCP 서버 · 표준 입출력 JSON-RPC · 포트 없음) · 플러그인 `.mcp.json` 이 방에서 띄웁니다 · 도구 `dispatch` `inbox` `jobs` `status` · 방이 아니면 모든 도구가 `E-05` · 일꾼이 없으면 `dispatch` 는 `E-01` ([명세 › SP-08](SPEC.md#sp-08-허브-도구-넷-mcp)) | 있음 |
| `hook <session \| prompt \| tool>` | Claude Code 훅 (플러그인 `hooks/hooks.json` 이 부릅니다 · 표준 입력 = 훅 입력 JSON) · 모드 방 · 원자료 폴더 · 그 밖 ([명세 › SP-11](SPEC.md#sp-11-훅)) · 막은 까닭에 단어 · 경로를 쓰지 않습니다 | 있음 |
| `--statusline` | statusLine 기록 — 표준 입력 JSON 의 정해진 여섯 칸만 읽고 (`transcript_path` 는 열지 않습니다) 이번 달 사용을 `usage\` 에 남기고 한 줄 `DIODE  room ok  effort high  month 12%` 를 찍습니다 · 언제나 종료 코드 0 ([명세 › SP-13](SPEC.md#sp-13-statusline-기록)) | 있음 |
| `--status --json [--room 폴더]` | 상태 명령 (바깥 인터페이스 · 읽기 전용 · JSON 한 줄) · `0` OK · `2` 사용법 오류 · `1` 내부 실패 (JSON 없음) | 있음 |
| `propose <report.json>` | 일꾼 (사내 LLM) 이 보고 초안을 내는 명령 · 미리 봉인해 걸리면 `{"queued": false, "hits": [...]}` (단어 없음) 과 종료 코드 `2` · 통과하면 데이터 폴더 `queue\` 에 넣고 `{"queued": true, "job": …}` · 허브가 그 job 의 가명 표로 다시 봉인 → D7 → 확정 창 → outbox ([명세 › SP-09](SPEC.md#sp-09-확정-창--보고-내기-propose)) | 있음 |
| `confirm <요청 파일>` | 확정 창 (허브가 부릅니다 · 사람이 보낼 바이트를 보고 [보내기] · [넘기기]) · 결과는 표준 출력 JSON 한 줄 · `0` 보냄 · `3` 버림 · 고치기 · 시간 초과 · `2` 요청 꼴 오류 · `1` 창을 못 띄움 ([명세 › SP-09](SPEC.md#sp-09-확정-창--보고-내기-propose)) | 있음 |
| `scan` | 표준 입력의 글을 데이터 폴더의 사전 · 설정으로 검사 (D2 · D3 · D5) · 표준 출력에 JSON 한 줄 · 표준 오류에 `DIODE …` 한 줄 · 종료 코드 `0` 통과 · `2` 막음 (사전이 없거나 비어도 `2`) · 단어 · 값은 찍지 않습니다 | 있음 |
| `lib names <이름>` | 허용 라이브러리의 공개 이름 | 아직 없음 |

- 아직 없는 명령은 `아직 없음 (v0.0)` 을 표준 오류에 쓰고 종료 코드 2 로 끝납니다. 계약은 [명세 › SP-16](SPEC.md#sp-16-명령--종료-코드) 입니다.
- `check` 가 `결과: 확인 필요` (종료 코드 3) 를 내는 때는 환경 변수 `DIODE_HOME` 이 설정되어 있을 때입니다. 테스트용 자리라서 사람이 확인합니다.

Terminal–1 같은 다른 도구가 부르는 읽기 전용 상태 명령 (`--status --json`) 의 칸 · 값 범위는 [Terminal–1 사내 작업 지침 › 04-5](https://github.com/leebobegogigug-blip/Works/blob/8df8bca44a80a8034e343f646967e2eea744a28b/docs/plans/terminal-1-claude-guide.md) 의 format 1 계약이 정본입니다. 칸의 뜻은 [명세 › SP-12](SPEC.md#sp-12-상태-명령).

## 알려진 한계

- **아직 쓸 수 없습니다 (v0.0).** 훅은 막지만 허브 · 확정 창이 없어 일을 넘기거나 보고를 받을 수 없습니다.
- **설정 전에는 그 밖의 폴더가 지켜지지 않습니다.** 데이터 폴더에 사전 · 설정이 없으면 훅은 그 밖의 폴더의 말을 통과시키고 세션 시작 때 알리기만 합니다 (방은 설정 없이 막습니다). 사전 · 설정이 깨져 있으면 막습니다.
- **플러그인을 끄면 보호가 없습니다.** 훅은 플러그인과 함께만 돕니다.
- **상태 명령의 `seatbelt: on` 은 플러그인이 켜졌다는 뜻이 아닙니다.** 설정 (사전 · 원자료 폴더 목록) 이 있다는 뜻입니다.
- **D7 판정 (사내 LLM) 은 환경 변수 덮어쓰기를 받지 않습니다.** `llm` 설정의 `{env:이름}` 참조도 받지 않습니다. 다만 `ca_file` 을 적지 않으면 TLS 인증서 자리를 OpenSSL 이 `SSL_CERT_FILE` 환경 변수에서 찾을 수 있습니다 — `ca_file` 을 적으세요. 설정에 프록시 주소를 적은 경우에만 `no_proxy` 를 봅니다.
- **확정 창의 글은 마우스로 골라 복사할 수 있습니다.** 손으로 옮긴 글은 감사 기록에 남지 않습니다.
- **확정 창은 화면이 있어야 뜹니다.** 화면이 없는 환경 (원격 셸 · Windows 밖에서 `DISPLAY` 없음) 에서는 보내지 않습니다 (`E-07`). 글꼴은 Unifont 가 있으면 그것, 없으면 Consolas · D2Coding 순입니다.
- **훅은 `DIODE_HOME` 을 받지 않습니다.** 늘 기본 데이터 폴더를 봅니다 — 환경 변수로 다른 사전 · 설정을 물리지 못하게.
- **S-09 를 따르지 않습니다.** 나가는 검사 D7 (사내 LLM 판정) 은 works 의 [SPEC-llm](https://github.com/leebobegogigug-blip/Works/blob/13e56a0a5801da56dc18523363cd219ebf6d2e21/docs/SPEC-llm.md) 의 `llm` 설정 키를 따르지만, 환경 변수 덮어쓰기 (`<접두어>_BASE_URL` 등) 는 받지 않습니다. 사내 LLM 이 환경 변수로 판정 모델을 바꿔 D7 을 무력화할 수 있어서 AL-12 와 부딪히기 때문입니다 ([규칙 › S-09](../RULES.md#규약)).
- 이 저장소에서는 사내 TUI · 사내 Windows 를 볼 수 없습니다. 사내에서만 되는 확인은 [사내 마무리](INHOUSE.md) 로 남깁니다.
