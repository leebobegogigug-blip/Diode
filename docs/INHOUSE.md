# Diode 사내 마무리 — 공개 저장소와 사내 작업의 경계

이 문서는 사내 Claude 가 이 저장소를 마무리할 때 지키는 경계를 고정한다. 뼈대다 — 절차 · 계약 · 점검표는 해당 작업 (T15 · T16) 에서 채운다. 출처는 [기획서 › 07 사내 마무리](PLAN.md#사내-마무리--사내-claude-가-최종-검토-q5) 와 [R17](PLAN.md#11-리스크-대장) 이다.

## 왜 나누나

이 저장소는 공개다 ([규칙 › W-12](../RULES.md#w-12-공개-저장소다)). 사내 TUI 를 볼 수 없고 사내 이름을 쓸 수 없다. 그래서 일반 부분은 여기서 합성 자료로 만들고, 사내에서만 할 수 있는 부분은 사내 Claude 가 사내 PC 에서 마무리한다.

## 경계

| 여기서 (공개 저장소 · 합성 자료) | 사내에서 (사내 Claude · 사내 PC) |
|---|---|
| 다이오드 본체 · 검사기 · 확정 창 · 건네기 `clipboard` · `room` · 방 프로필 · 안전벨트 · 어댑터 **계약** · 가짜 TUI 로 계약 테스트 | 사내 TUI 어댑터 구현 · KIT-1 · KIT-2 를 사내 PC · 사내 TUI 판으로 다시 · 사내 모델 이름 · 사전 · 정규식 설정 · 사내 PC 에서 전체 테스트 · 코드 최종 검토 |

## 어댑터 계약 [제안]

- `name` · `check() → 결과 (effort 를 받는지 포함)` · `put(id, sealed_text, route)` · `get(id) → 답 또는 없음`.
- `route` 는 모델 · effort 두 값뿐이다. 어댑터는 봉인된 글만 받는다 — 원문 · 가명 표에 닿는 인자가 없다.
- 계약 테스트를 통과해야 설정에서 고를 수 있다. 계약을 확정하는 곳은 건네기 작업 (T11) 이다.

## 사내 이름은 공개 저장소로 돌아오지 않는다

- 사내 이름이 들어간 것 (어댑터 설정 · TUI 이름 · 모델 이름) 은 `.gitignore` 로 막힌 `adapters.local/` 또는 데이터 폴더 (`%LOCALAPPDATA%\diode`) 에만 둔다.
- 공개 저장소로 되돌아오는 것은 사내 이름이 없는 일반 코드뿐이다.
- 사내에서 고친 일반 코드를 되가져올 때는 diff 를 사람이 한 줄씩 본다. 되가져오기 전에 사내 PC 에서 `python tools/diode_check.py --strict --internal-words "<사내 낱말 목록 파일>"` 을 돌려 0 인지 본다 (낱말 목록은 사내 자리에만 두고 저장소에 두지 않는다 · 검사기는 낱말을 찍지 않는다).

## 검토 세션의 자리

- 사내 Claude 로 다이오드 코드를 검토할 때는 `D:\claude\diode` 에서 연다.
- `D:\claude` 에서 열지 않는다 — 방 (`D:\claude\room`) 과 소스를 한 세션이 같이 보게 된다.
- 원자료가 있는 폴더 · works 저장소 루트 (`D:\OPENCODE` — 데이터를 프로그램 폴더에 두는 앱이 있다) 에서도 열지 않는다.
- 검토 세션에도 안전벨트를 켠다 (L-20). 방이 아니므로 안전벨트 + `[질문]` 길이다.
- 검토 대상은 공개 코드뿐이고 사내 월 한도 안에서 한다.

## 사내에서 할 일

- 사내 TUI 어댑터를 계약대로 만들고 계약 테스트를 통과시킨다. TUI 에 훅이 없으면 `room` 을 끈다.
- KIT-1 · KIT-2 를 사내 TUI 판으로 다시 한다. 사내 Claude Code 판의 statusLine 입력 칸이 문서와 다르면 `--statusline` 을 맞춘다.
- 사내 모델 이름으로 KIT-6 (effort 별 비용) 을 재고, 사내 Claude Code 판에서 KIT-7 (허브가 뜨는지 · 창 · 환경 변수 · 도구 결과 모양) 을 다시 한다.
- `kit/run_kit.py` 를 사내 Windows 에서 `--python python` 으로 돌린다. 결과는 판정과 숫자만 공개 저장소로 가져온다.
- 사내 CLI 에 opencode 가 어떻게 물려 있는지 (명령줄 · MCP · 하위 에이전트) 확인하고, 설정 `worker.command` (예 `["opencode", "run", "{prompt}"]`) 와 `policy.inner_tools` (사내 이름은 사내에서만 적는다) 를 맞춘다. Claude 가 안쪽 도구를 직접 부르는 길이 하나도 남지 않았는지 (훅 deny) 확인한다.
- 코드 전체를 최종 검토한다.
